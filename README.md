# 재무상태표

기존 엑셀(`재무상태2025.xlsx`)의 구조를 그대로 옮긴 단일 HTML 재무상태표입니다.
엑셀에서는 기간(열)이 늘어날수록 입력이 힘들어지기 때문에, 기간을 버튼으로 계속 추가할 수 있게 만들었습니다.

## 사용법

`재무상태표.html` 파일을 브라우저로 열면 됩니다. 별도 설치나 서버가 필요 없습니다.

## 구성

| 영역 | 내용 |
|---|---|
| 자산 | 현금자산 · 투자자산 · 보험자산 · 사용자산, 각 소계와 자산 합계 |
| 부채 | 신용대출 · 임대보증금, 각 소계와 부채 합계 |
| 순자산 | 자산 − 부채, 직전 기간 대비 상승률 |
| 주요 자산현황 | 지수투자(연금저축 · ISA · 증여) · 코인 · 현금자산 상세 |
| 부동산·자동차 계산 | 부동산 = 파라곤 + 신대, 자동차 = 싼타페 + 그렌져 |
| 자산배분 | 주식 · 부동산 · 코인 · 현금성자산 비율과 환산MDD |
| 참고 | 수익률 기준값, 포트폴리오비주얼라이저 계산, 1972-2024 |

## 기능

- **기간 추가** — 빈 기간을 만들거나 직전 기간 값을 복사해 추가합니다. 기간 이름은 표 머리글에서 바로 수정합니다.
- **가로 스크롤** — 기간이 늘어나도 `구분`·`항목` 열은 왼쪽에 고정됩니다.
- **상세 입력 연동** — 켜면 카뱅 · 예금(농협) · 청약저축 · 장기저축 · 목돈급여 · 지수 · 비트코인이 상세 합계로 자동 계산됩니다.
- **자동 저장** — 입력 즉시 브라우저(localStorage)에 저장됩니다.
- **JSON 내보내기 / 불러오기** — 백업하거나 다른 PC로 옮길 때 사용합니다.
- **초기화** — 엑셀 원본 상태로 되돌립니다.

## 계산 방식

엑셀 원본 수식을 그대로 따릅니다.

```
현금·투자·보험·사용자산 합계 = 각 항목의 합
자산 합계 = 네 소계의 합
순자산   = 자산 합계 − 부채 합계
상승률   = (당기 순자산 / 전기 순자산 − 1) × 100

자산배분
  주식       = 투자자산 합계 − 비트코인
  코인       = 비트코인
  현금성자산 = 현금자산 합계
  부동산     = 순자산 − 주식 − 코인 − 현금성자산   (엑셀과 동일한 잔차 방식)
  비율       = 각 금액 / 순자산
  환산MDD    = 비율 × MDD
```

## 주의

자산배분표의 `부동산`은 잔차로 계산되어 부채 전액이 이 항목에서 차감됩니다.
그래서 환산MDD가 실제 하방 위험보다 낮게 잡히며, 표 아래에 총자산 익스포저 기준 수치를 참고로 함께 표시합니다.
