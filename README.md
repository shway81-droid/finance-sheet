# 재무상태표

기존 엑셀(`재무상태2025.xlsx`)의 구조를 그대로 옮긴 단일 HTML 재무상태표입니다.
엑셀에서는 기간(열)이 늘어날수록 입력이 힘들어지기 때문에, 기간을 버튼으로 계속 추가할 수 있게 만들었습니다.

## 사용법

`재무상태표.html` 파일을 브라우저로 열면 됩니다. 별도 설치나 서버가 필요 없습니다.

## 구성

| 영역 | 내용 |
|---|---|
| 자산 | 현금자산 · 투자자산 · 보험자산 · 사용자산, 각 소계와 자산 합계 |
| 부채 | 신용대출 · 임대보증금, 각 소계와 부채 합계 |
| 순자산 | 자산 − 부채, 직전 기간 대비 상승률 |
| 주요 자산현황 | 지수투자(연금저축 · ISA · 증여) · 코인 · 현금자산 상세 |
| 부동산·자동차 계산 | 부동산 = 파라곤 + 신대, 자동차 = 싼타페 + 그렌져 |
| 자산배분 | 주식 · 부동산 · 코인 · 현금성자산 비율과 환산MDD |
| 참고 | 수익률 기준값, 포트폴리오비주얼라이저 계산, 1972-2024 |

## 기능

- **기간 추가** — 빈 기간을 만들거나 직전 기간 값을 복사해 추가합니다. 기간 이름은 표 머리글에서 바로 수정합니다.
- **가로 스크롤** — 기간이 늘어나도 `구분`·`항목` 열은 왼쪽에 고정됩니다.
- **상세 입력 연동** — 켜면 카뱅 · 예금(농협) · 청약저축 · 장기저축 · 목돈급여 · 지수 · 비트코인이 상세 합계로 자동 계산됩니다.
- **자동 저장** — 입력 즉시 브라우저(localStorage)에 저장됩니다.
- **기기 간 동기화** — 저장소의 `data.json`이 데이터 원본입니다. 아래 참고.
- **JSON 내보내기 / 불러오기** — 백업하거나 수동으로 옮길 때 사용합니다.
- **초기화** — 엑셀 원본 상태로 되돌립니다.

## 기기 간 동기화

데이터는 Firebase Realtime Database 의 `finance` 노드에 있습니다.
**기기마다 등록할 것이 없습니다.** 주소를 열기만 하면 어디서든 읽고 쓸 수 있습니다.

- 처음 여는 기기는 서버 데이터를 그대로 가져옵니다.
- 값을 고치면 1.5초 뒤 자동으로 올라갑니다.
- 다른 기기는 열 때와 1분마다 확인해서, 더 최신 데이터가 있으면 알림만 띄웁니다.
  (편집 중인 내용을 말없이 덮어쓰지 않기 위해 적용은 사용자가 누를 때만 합니다.)

두 기기에서 동시에 고치면 나중에 올린 쪽이 남습니다.
다른 기기로 옮겨 갈 때는 `서버에서 불러오기`를 먼저 누르고 편집하는 편이 안전합니다.

### 보안 규칙

`database.rules.json` 에 있으며 `firebase deploy --only database` 로 반영합니다.

```json
{ "rules": { ".read": false, ".write": false,
             "finance": { ".read": true,
                          ".write": "newData.hasChildren(['version', 'periods'])" } } }
```

`finance` 노드만 열려 있고, `version` 과 `periods` 를 가진 쓰기만 허용합니다.
그래서 삭제(DELETE)나 엉뚱한 형식의 쓰기는 거부됩니다.
다만 형식만 맞으면 주소를 아는 사람이 덮어쓸 수는 있으므로, `data.json` 을 백업으로 남겨 둡니다.

## 계산 방식

엑셀 원본 수식을 그대로 따릅니다.

```
현금·투자·보험·사용자산 합계 = 각 항목의 합
자산 합계 = 네 소계의 합
순자산   = 자산 합계 − 부채 합계
상승률   = (당기 순자산 / 전기 순자산 − 1) × 100

자산배분
  주식       = 투자자산 합계 − 비트코인
  코인       = 비트코인
  현금성자산 = 현금자산 합계
  부동산     = 순자산 − 주식 − 코인 − 현금성자산   (엑셀과 동일한 잔차 방식)
  비율       = 각 금액 / 순자산
  환산MDD    = 비율 × MDD
```

## 주의

자산배분표의 `부동산`은 잔차로 계산되어 부채 전액이 이 항목에서 차감됩니다.
그래서 환산MDD가 실제 하방 위험보다 낮게 잡히며, 표 아래에 총자산 익스포저 기준 수치를 참고로 함께 표시합니다.
